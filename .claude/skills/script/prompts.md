# Script Narration Style Guide

## Core Rules

- Every sentence must earn its place: new info, emotional shift, or surprise
- Short sentences (under 15 words). Mix lengths for rhythm
- Active voice only. No passive constructions
- Vary sentence openings: questions, facts, fragments, exclamations
- NEVER use filler: 「其實」「基本上」「事實上」「總之」「然而」
- NEVER use greetings: 「大家好」「歡迎觀看」「哈囉」
- Write spoken language, NOT written language
- Natural particles: 「超」「根本」「啦」「吧」「耶」(use sparingly)
- Reduce 「欸」 — some viewers dislike overuse
- Avoid trendy slang like 「狂」「絕了」 — use timeless expressions

## Scientific Verification (Critical)

- Every factual claim MUST be from the research brief
- Do NOT fabricate statistics, dates, names, or studies
- When uncertain, use hedging: 「據研究」「目前認為」
- Prefer well-documented facts over sensational but unverifiable claims

## Short-Form Rules (30-90 seconds)

- Total video: 30-90 seconds. Each scene: 15-30 seconds MAX
- Pick ONE narrative structure:
  - **懸念揭曉型**: Hook(拋出驚人事實) → 鋪墊(為什麼？) → 揭曉(意想不到的答案)
  - **誤導反轉型**: Hook(引導觀眾往A想) → 展開(加強A的印象) → 反轉(其實是B！)
  - **層層遞進型**: Hook(小驚喜) → 升級(更大的驚喜) → 炸裂(最震撼的事實)

## Opening Hook (First 3 Seconds)

Pick one technique:
- **反直覺事實**：「飛機窗戶以前是方的」
- **挑戰認知**：「你每天做的這件事，居然是錯的」
- **懸念問句**：「為什麼日本的水溝蓋這麼美？」
- 前 3 秒必須完成 hook，沒有任何前置鋪墊

## Body (Middle Scenes)

- 用「開放迴圈」：解答上一個問題的同時，拋出新的懸念
- 加入情緒轉折：從好奇轉為震驚、從震驚轉為理解
- 每 5-7 秒引入新元素（新事實、新角度、新情緒）

## Closing (Final Scene)

- **反轉結尾**：最後一句推翻前面的認知
- **回扣開頭**：呼應第一場景丟出的問題
- **餘韻結尾**：留下一個讓人繼續想的問題
- 不要用 CTA（訂閱、按讚）
- 不要用總結句（「所以說」「總而言之」）

## Narration Specs

- 字數限制：50-80 個中文字/場景（約 15-25 秒口語速度）
- 每句話 ≤ 15 字。長短交替製造節奏感
- 句型要多變：問句、驚嘆句、斷句、陳述句交替
- 情緒弧線：好奇 → 驚訝 → 恍然大悟

## Example (Style Reference)

主題：為什麼飛機窗戶是圓的？

場景1（Hook）：
「1950年代，有一種飛機叫彗星客機。超美、超先進。
但它有個致命的設計——方形窗戶。
結果？兩架飛機，空中解體。」

場景2（展開）：
「方形窗戶的四個角，會集中所有壓力。
飛到高空，金屬疲勞，裂縫就從角落開始。
一裂開？整架飛機像氣球一樣炸開。」

場景3（反轉結尾）：
「所以工程師把窗戶改成圓的。沒有角，壓力均勻分散。
就這麼一個小改變，從此再也沒有因為窗戶而墜機。
你每次搭飛機看到那個圓窗戶——它救了你的命。」
