# Quick Reference: Hook Formulas for Script Generation

**For immediate use in script generation and content farm pipeline**

---

## THE 4 MOST EFFECTIVE HOOKS (Priority Order)

### 1. PATTERN INTERRUPT + QUESTION (🔥🔥🔥 Highest Performance)
- **First 1 second:** Visual/text interrupt (unexpected, contrasting, or movement-based)
- **Seconds 1-3:** Pose a specific question
- **Why:** Combines novelty (brain stops scrolling) + curiosity (brain must resolve)
- **Completion impact:** +41% higher completion rates (TikTok data)
- **Best for:** All content types

**Formula:**
```
[Visual interrupt/text] → [Specific question] → [Deliver answer by end]
```

**zh-TW Example:**
```
[Text overlay: "為什麼月薪10萬還存不到錢？"]
→ [Voiceover: "我發現了一個90%的人都犯的致命錯誤..."]
→ [Reveal the mistake + solution in 20 seconds]
```

---

### 2. CURIOSITY GAP (🔥🔥🔥 Highest Watch Time)
- **Structure:** Bold claim + incomplete information = gap viewer must fill
- **Completion increase:** +145% watch time increase
- **Share increase:** +178% higher share rates vs. direct statements
- **Best for:** Educational, mystery, reveal-based content

**Formula:**
```
"Most people [do X wrong/don't know about Y]. Here's why..."
```

**Examples:**
- "There's a reason no one talks about this skincare ingredient."
- "Everything you've been told about morning routines is wrong."
- "Most people use their phone charger wrong. Here's why."

---

### 3. TRANSFORMATION REVEAL (🔥🔥🔥 Highest Completion)
- **Structure:** Setup (0-10s) → Unexpected twist/result (10-30s)
- **Why:** Viewers watch to the end to see "what happens"
- **Completion rate:** 70%+ typical
- **Best for:** Before/after, unexpected reveals, secrets

**Formula:**
```
[Establish scenario + expectation] → [Surprise/dramatic result]
```

---

### 4. SPECIFIC RESULT/DATA (🔥🔥 High Credibility)
- **Structure:** Concrete metric + specific outcome (not vague)
- **Why:** Builds authority + creates concrete promise
- **Best for:** Tutorials, skill-building, transformation

**Formula:**
```
"[Specific number/metric] [outcome]. Here's how..."
```

**Examples:**
- "This 5-second edit doubled my watch time." (vs. "editing trick")
- "I gained 100k followers in 30 days. Here's how."

---

## HOOK SELECTION BY CONTENT TYPE

| Content Type | Primary Hook | Secondary Hook | Avoid |
|---|---|---|---|
| **Knowledge/Tutorial** | Curiosity Gap + Question | Pattern Interrupt | Generic "here's a tip" |
| **Before/After** | Transformation Reveal | Specific Result | Lengthy setup |
| **Motivational** | Contrarian Statement | Emotional Arousal | Abstract promises |
| **Entertainment** | Pattern Interrupt | Emotional Arousal | No payoff hint |
| **Trending Topic** | FOMO/Relevance | Question | Delayed context |
| **Product Feature** | Problem → Solution | Specific Result | Feature-first approach |

## TIMING TEMPLATE (All Hooks)

**30-60 second video structure:**

```
0-1s    : PRE-HOOK (visual/text interrupt OR opening statement)
1-3s    : ENGAGEMENT (question / curiosity gap / claim)
3-50s   : BODY (deliver value, answer, or transformation)
50-60s  : CTA (call-to-action, follow-up, or cliffhanger)
```

**Critical retention checkpoints:**
- 70%+ must remain at 3-second mark
- 60%+ must reach end of 30-second video
- 40%+ swipe-away in first 3s = hook failed and needs revision

## ZH-TW SPECIFIC HOOK TEMPLATES

### 1. 痛點直戳 (Pain Point Directly Addressed)
```
"[Specific problem experienced by audience]...你也是嗎？"

Example: "為什麼月薪10萬還是存不到錢？"
Example: "為什麼你的內容流量一直上不來？"
```

### 2. 數據衝擊 (Surprising Data/Statistic)
```
"[Counterintuitive percentage/number]的人都[negative outcome]"

Example: "88%的人在這個年紀還沒開始理財"
Example: "超過70%的創作者在第一個月就放棄了"
```

### 3. 反轉期待 (Expectation Reversal/Contrarian)
```
"你知道嗎？[commonly believed thing]其實[opposite truth]"

Example: "喝那麼多水其實沒必要"
Example: "早起根本不是成功的秘訣"
```

### 4. 秘訣揭露 (Secret/Insider Knowledge)
```
"只有[少數人/行家]知道的[內幕/技巧]..."

Example: "YouTube推薦演算法其實是這樣..."
Example: "品牌方不想讓你知道的定價秘密..."
```

## CRITICAL METRICS TO HIT

| Metric | Target | Failure Point |
|--------|--------|---|
| **Intro Retention (3s)** | >70% | <50% |
| **Completion Rate (30s)** | >60% | <40% |
| **Swipe-Away Rate (3s)** | <20% | >60% |
| **Engagement Rate (zh-TW)** | >10% | <5% |
| **Average % Viewed** | >80% | <70% |

**If missing targets:**
- Hook too weak → Replace with Pattern Interrupt + Question combo
- Slow start → Cut setup time by 50%
- Value not clear → Add specific metric/result to opening

---

## SCRIPT GENERATION CHECKLIST

Before finalizing any script:

- [ ] Hook selected (from 4 primary options)
- [ ] First 1 second has visual/text interrupt OR direct statement
- [ ] Question posed or curiosity gap created in 1-3 second window
- [ ] Value/answer delivered by 50-second mark
- [ ] No filler language (「欸」,「嗯」minimized)
- [ ] Specific metrics/results included (not vague)
- [ ] CTA clear and specific (not generic "like and follow")
- [ ] Timeless phrasing used (avoid trendy slang)
- [ ] Total length 30-90 seconds
- [ ] Pacing maintains engagement (no dead zones >5 seconds)
