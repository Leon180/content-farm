# 簡報式知識影片：寫稿規則（deck-outline 與 deck 共用）

頻道定位：**台灣科技產業拆解**（中文版 Asianometry）。主持是聲音人格「晶片貓」——資深、冷面幽默、明確是虛構角色，不是真人專家。

以下四條是**硬規則**。違反任何一條就是不合格的稿子，要重寫，不是「下次注意」。

## 規則 1：艱深名詞先比喻，再定義

- 每個專有名詞（HBM、CoWoS、晶圓代工、良率、製程節點、毛利率、EUV……）第一次出現時：
  1. **先**給一個國高中生聽得懂的比喻（「良率就像烤一盤餅乾，烤焦的越少越賺」）；
  2. **再**給精確定義（「良率是一片晶圓上能正常運作的晶片比例」）。
- 同一支片同一個名詞只比喻一次，之後直接用。
- 公式**最多一行**，而且唸得出來；寧可不放。
- 比喻不能扭曲事實。比喻與事實衝突時，刪比喻。

## 規則 2：每 2–3 張投影片一個輕鬆段落，八卦與冷笑話輪流

- 在 deck.json 用 `"beat": "gossip"` 或 `"beat": "joke"` 標記那一張。lint 會檢查：連續超過 3 張沒有 beat、或連續兩個 beat 同類型，都會被點名。
- **八卦（gossip）**：產業軼事、幕後故事、公司歷史上的轉折。
  - 必須附 `source_ids`，跟其他事實一樣（schema 會擋沒有來源的 gossip）。
  - **不放**針對具名人物的傳聞、私生活、未經證實的說法。公司層級的公開紀錄可以。
- **冷笑話（joke）**：可以原創。晶片貓人設是冷面、自嘲、一句話帶過，不鋪陳、不解釋笑點、不嘲諷特定族群或真人。
- 輕鬆段落是講稿裡的一兩句話，不是整張投影片的主題。

## 規則 3：每支片有原創論點或結構，不寫百科摘要

- 大綱階段就要寫出一句**論點**（thesis），例如「台積電賺的不是做晶片的錢，而是讓別人不用蓋廠的錢」。整支片都在證明或拆解這句話。
- 結構三選一或混用：**比較**（A vs B、今昔對照）、**拆解**（輸入→處理→輸出、成本結構、供應鏈分段）、**觀點**（反直覺結論＋證據）。
- **版型依題目變化**，不要每支都是「標題 → 5 點列表 → 結論」：
  - bullets 不得超過全片一半（lint `bullets-heavy`），全片至少用 3 種版型。
  - 有一個關鍵數字就用 `big_number`；有兩方就用 `compare`；有時間演進就用 `timeline`；收束金句用 `quote`。
- 不照念新聞稿或論文摘要。來源是證據，講稿是自己的話。

## 規則 4：不給投資建議；AI／產業類頁尾印「資料截至」

- 不談個股買賣、目標價、進出場時機，不說「值得買」。lint 會掃「買進、賣出、加碼、減碼、目標價、進場、出場、抄底、停損」等字。
- ai、tech 類別 deck 必填 `as_of: "YYYY-MM"`（schema 強制），模板頁尾自動印「資料截至 YYYY-MM」與「非投資建議」。
- 片尾口播一句「本頻道只拆產業，不報明牌」或同義句。

## 事實與來源

- 每個數字都要有 `source_ids`（lint `unsourced-number`）。來源寫進 deck 的 `sources[]`，`id` 短、`title` 可讀、`url` 盡量填一手來源（年報、法說會、政府統計）。
- 還沒查證的數字：整份 deck 設 `"draft_data": true`。每張投影片會被蓋「示意數字・待查證」章，lint 會判定不可發布。**不要把待查證數字偽裝成確定值。**
- 區分「已證實／公司宣稱／推測」，講稿裡用字要讓觀眾聽得出差別（「據公司說法」「業界估計」）。

## 三種類別的差異

| | tech（預設，產業拆解） | ai | knowledge |
|---|---|---|---|
| 時效 | 中高；規格與財務數字附年份 | 極高；benchmark、價格必附來源 | 低；可長青 |
| 講稿重點 | 生意怎麼運作：成本結構、供應鏈位置、取捨；台灣在哪一段 | 機制直覺化；明確區分已證實／廠商宣稱／推測 | 懸念開場 → 層層遞進 → 反直覺結論 |
| 常用版型 | compare、big_number、timeline | compare、big_number、timeline | quote、timeline、big_number |
| `as_of` | 必填 | 必填 | 選填 |
| pronunciation_map | 中度（晶片型號、公司英文縮寫） | 重度（模型名、縮寫） | 輕度（人名、地名） |
| 主題 | 深灰底、橘色強調、等寬數字 | 深藍底、青色強調 | 米白底、襯線標題 |

## 晶片貓（聲音人格與吉祥物）

- 開場固定句型：「我是晶片貓，今天用 N 張圖把 X 拆給你看。」
- 語氣：資深、平穩、冷面；愛講「這個數字其實是……」。不用網路流行語堆砌。
- 角落吉祥物：投影片可加 `"mascot": {"pose": "point|think|smug|shocked"}`。pose 依該頁情緒選（指重點用 point、拋問題用 think、講完冷笑話用 smug、揭露驚人數字用 shocked）。沒有素材時角落自動留空，不影響渲染。
