# 縮圖規則（四個頻道共用）

2026-10-17。政策部分引自 `youtube-policy-review-2026-10.md` 的 A4、B、D5（該文件的等級照抄：🟢 讀過官方原文，🟡 二手）。「有效手法」是業界共識加上我的判斷 🟡，**要用 YouTube「測試與比較」的實際數據來驗**，不要當定律。

## 1. 硬規則（違反就不上傳）

| # | 規則 | 依據 |
|---|---|---|
| H1 | **縮圖上的每一句話、每一個數字，都要在影片前 60 秒內兌現**。數字必須在旁白裡逐字出現。QC 的 `thumbnail_promise` 會自動檢查 | 政策 A4 🟢：「maliciously misleading titles, thumbnails … to trick users into clicking」屬於垃圾內容政策，可能被移除，不只是降低曝光 |
| H2 | 不承諾片中沒有的東西：沒拍到的畫面、沒講的結論、誇大的數字都不行 | 同上；官方舉例是「標題說整場比賽，影片只有片段」 |
| H3 | 聳動程度不能超過內容：不放血腥或驚嚇畫面（妖怪題材尤其要注意），不用「震驚」「崩潰」這類跟內容不符的情緒字 | A7：暴力、恐怖畫面不放縮圖和開頭 |
| H4 | 不用他人的肖像、商標或官方角色圖。動畫頻道不放官方角色或截圖，AI 圖也不能畫出近似官方角色的人物 | `cel.yaml` 規則、A7 |
| H5 | AI 生成的主視覺（key art）要寫進 credits：模型、授權、提示詞。畫面上不必標「AI 示意」，但說明欄的 AI 揭露要照頻道設定 | 頻道 `ai_disclosure: true`、`credits.json` 規則 |
| H6 | 不直接拿標題投影片當縮圖 | D5-1 |

## 2. 有效手法（🟡，以 A/B 數據為準）

1. **一張圖只講一件事**：一個主角（角色或畫作）、一個物件、一句話。三樣以上就會變成雜訊。
2. **3–6 個大字**，手機首頁看得清：首頁縮圖寬約 320–360 px，所以 1280 寬的原圖裡，大字至少要 120 px（縮小後約 30 px）。產生器目前上限是 10 字。
3. **角色大表情**：驚訝、得意、無言比微笑有張力。要用頻道角色，不用真人臉。
4. **高對比**：大字加描邊或色塊底；主色對比 ≥ 4.5:1。避免整張中間調。
5. **好奇缺口**：問句或對比要讓人想知道答案，但答案必須在片中前 60 秒給出（H1）。例如「一條尾巴？」、「7,722 mm²」。
6. **數字／對比型**：一個大數字，或「A vs B」兩個數字，最適合產業拆解。
7. **品牌一致**：同一頻道的縮圖要能一眼認出是同一個頻道（配色、角色位置、字體）。

## 3. 三種版型（產生器 `layout`）

| 版型 | 什麼時候用 | 組成 |
|---|---|---|
| `character`（a） | 預設；頻道角色有戲的時候 | 頻道角色大表情（晶片貓用向量 rig，其他頻道用 PNGtuber 包）＋大字＋一行副標 |
| `keyart`（b） | 題目本身有強烈畫面（妖怪、產品） | 滿版主視覺（公共領域畫作或 klein 生的 key art）＋問句 |
| `compare`（c） | 有一個驚人的數字或對比 | 一個或兩個大數字（「9 vs 1」）＋標籤；可加角色小圖 |

## 4. A/B 測試

- YouTube「測試與比較」一次最多 3 張，以**觀看時間佔比**判定勝出（🟢 answer/13861714）。所以 a、b、c 三款剛好放一組。
- **Shorts 不能用「測試與比較」**（🟢 同上）。Short 的三款封面只能人工挑一張，或分支發佈時輪替。
- 每款都要通過 H1 的承諾檢查，不是只檢查勝出那張。

## 5. v2 修訂（2026-10-24，縮圖研究；原始筆記 `artifacts/thumbnail-v2/research-notes.md`）

標「數據」＝有樣本的相關性研究（Eden 507,478 支長片；vidIQ 500 支；皆**沒量 CTR**，只比「爆紅 vs 低表現」，差距 < 約 2.5 個百分點不顯著）；「官方」＝YouTube 說明頁；「經驗」＝廠商部落格。

| # | 規則 | 等級 |
|---|---|---|
| V1 | 大字少字：4–6 詞最常見於爆紅片（30.6% vs 26.5%，表中最大差距）；7 詞以上反而偏低 | 數據 |
| V2 | 單一焦點、構圖別太複雜、字要好讀、圖要盡量大（官方原文 “Try not to make the design too complex”） | 官方 |
| V3 | 縮圖要用「描述性」文字（官方建議）；但「逐字重複標題」與「完全不同」的差距 ≈ 0（6.3% vs 6.8%、39.2% vs 39.1%），所以「與標題互補」是通則，**沒有實證**，只當設計習慣 | 官方＋數據：無差異 |
| V4 | 臉：有臉 84.2% vs 82.2%，微笑反而較低（21.2% vs 23.4%），誇張表情只在大頻道明顯；動物／無臉頻道**沒有直接證據**，不要硬塞臉；用「衝突、動作」取代表情 | 數據（相關） |

| V6 | 手機小圖可讀：各家說法 120／154×86／168 px 寬，皆廠商；我們取 168×94 當檢查尺寸，字高 ≥ 14 px | 經驗 |
| V7 | 規格：16:9、JPG/PNG、≤ 2 MB（手機上傳）；官方頁寫建議 3840×2160、舊頁 1280×720，兩者並存，我們輸出 1280×720 < 2 MB | 官方 |
