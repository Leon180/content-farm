# 角色設計原則（第二輪）：從 Leon 選的 IP 學原則，不學長相

證據等級：本文全部是設計分析 🟡（我的判讀，依據是對這些作品公開形象的一般認識）。沒有引用一手訪談，也沒有逐張量測原作；頭身比、配色數這類數字都是約略值。
**用途**：把原則轉成生圖提示詞的描述語。提示詞裡**不出現任何 IP 名稱、角色名、作者名**，也不寫「in the style of」（`tools/r2_prompts.py` 的禁字檢查會擋）。

## 0. 第一輪為什麼醜（Leon：「好醜」）

先講失敗，再談學習。逐條對照：

| 第一輪的做法 | 問題 |
|---|---|
| 晶片貓系眼睛：琥珀虹膜＋直瞳＋兩顆高光，眼睛佔臉約 30% | 「兇」而且資訊太多。可愛 IP 幾乎都是小點眼或單色圓眼 |
| 一隻角色 5–7 個顏色（銀藍、白斑、粉耳、金、青綠、藏青、斗篷） | 縮到 300 px 時變成一團雜訊，辨識不出主色 |
| 外框（濾鏡）、內線、紋路，三種線寬 | 看起來像「向量圖示」，不像「角色」 |
| 道具疊在身上（斗笠＋斗篷＋燈籠、帽 T＋馬克杯） | 剪影被道具吃掉，角色本身不見了 |
| 個性只寫在文件裡 | 臉上看不出性格，表情是通用的 ^_^ 和 O_O |

## 1. 逐一分析

### 1a. 台灣在地圖文 IP（台式幽默、吐槽感）

- **輪廓**：極簡的圓頭或方頭，幾乎沒有細節；辨識度靠「一個怪點」，例如一撮毛、特定的嘴型、一個常拿的東西。
- **頭身比**：1.5–2.5 頭身，常常只畫上半身或頭。
- **眼睛**：小黑點、兩條線，或死魚眼半閉。**面無表情就是笑點**。
- **配色**：1 個主色＋白，有時整隻幾乎是白的，大量留白。
- **線條**：手繪麥克筆感，略抖、粗細不勻。親切，像是「自己也畫得出來」。
- **表情誇張度**：平常很平，失控時極端變形（臉垮掉、大汗、眼神死）。**反差**是核心。
- **個性設定**：一個生活化的缺點（懶、厭世、嘴賤、愛吃），台詞是吐槽或碎念，貼近上班族、學生的日常。
- **可延伸性**：靠「情境」延伸，不靠能力。同一隻角色可以套任何節日和職場梗；貼圖化非常容易。

### 1b. 療癒小動物系（小、軟、圓的一群角色）

- **輪廓**：麻糬、饅頭形，底部平，幾乎沒有脖子。
- **頭身比**：1–1.5 頭身，頭和身體常常是同一團。
- **眼睛**：很小的黑點，**間距寬、位置低**（臉的中下方），這是幼態感的關鍵；嘴也很小，有時在兩眼之間。
- **配色**：一個淺色、粉色主色＋白，每隻角色換一個主色，整組放在一起就是一盒馬卡龍。
- **線條**：細、柔的深褐或灰黑線，不用純黑。
- **表情誇張度**：中等，但「哭」和「慌」很常見，靠小汗滴、淚珠、抖動線。**脆弱感**讓人想保護。
- **個性設定**：每隻都有一個小自卑或小執念（怕冷、自認不是某種東西、躲在角落），用一句話講得完。
- **可延伸性**：**群像**：同一套造型規則換物種、換食物就能長出新角色；彼此的關係本身就會產生故事。

### 1c. 國民級冒險、科幻 IP（怪獸收集系、未來道具系）

- **輪廓**：塗黑剪影也認得出來，靠**一個招牌部件**（特殊的耳、尾、口袋、鈴鐺）。部件常常跟能力或功能綁在一起。
- **頭身比**：2–2.5 頭身，身體夠做動作（跑、跳、指東西）。
- **眼睛**：中大的單色圓眼＋一顆高光，比療癒系大、比少女漫畫小。表情幅度最大。
- **配色**：2–3 個主色，其中一個高彩度的**招牌點綴色**（臉頰、鈴鐺、項圈），面積小但永遠在同一個位置。
- **線條**：乾淨、粗細一致的黑或深色外框，內部線很少。
- **表情誇張度**：高，張大嘴笑、生氣冒煙，用整個身體表演。
- **個性設定**：一個核心特質（好奇、膽小、貪吃），加上一個跟能力相關的口頭禪或叫聲。
- **可延伸性**：**能力和道具**可以無限延伸劇情（一集一個道具、一隻一種能力），而且角色本身就是故事引擎。

## 2. 共通原則（我們用的版本）

| # | 原則 | 生圖提示詞怎麼寫 |
|---|---|---|
| P1 | **剪影測試**：塗黑也認得；只有**一個**招牌部件，而且跟頻道主題綁在一起 | `strong simple silhouette, one signature feature: …` |
| P2 | **頭大身小**：1.5–2.5 頭身，頭的寬度大於或等於身體 | `about two heads tall, big round head, small body` |
| P3 | **眼睛少即是多**：小點眼或單色圓眼＋一顆高光；間距寬、位置偏低 | `tiny black dot eyes set wide apart and low on the face` |
| P4 | **≤3 色**：1 個主色＋白，或主色＋1 個招牌點綴色；不用漸層和陰影 | `one main colour plus white, one small accent colour, flat colours, no shading` |
| P5 | **一種線寬**：粗、乾淨、內部線很少（台式款可以用手繪抖線） | `bold clean outline of one thickness, almost no inner lines` |
| P6 | **反差表情**：平常平、失控時極端；吐槽頻道用死魚眼 | `deadpan half-closed eyes` / `exaggerated panic with big sweat drops` |
| P7 | **一句話個性**：一個缺點＋一個執念，台詞從缺點長出來 | 寫在每張的一句說明，不進 prompt |
| P8 | **故事引擎**：招牌部件或道具能一直產生新段子 | `holding …` / `… instead of a tail` |
| P9 | **砍細節**：不要紋路、不要配件堆疊，最多一個道具 | `minimal details, no patterns, at most one small prop` |
| P10 | **可延伸成一組**：同一套規則換物種、換主色，就能長出配角或跨頻道家族 | 同頻道內固定畫風，只換物種和主色 |

## 3. 套到四個角色位

| 角色位 | 用哪幾條最重要 | 方向 |
|---|---|---|
| 妖怪溯源所（說書／守門） | P1、P8、P4 | 剪影上有一個「民俗物件」當招牌部件，例如燈籠、硃砂印、獨角、符紙、羅盤。主色用宣紙米白或墨黑，點綴用硃砂紅。畫風用療癒系加水墨筆觸。恐怖感只放在表情裡（嚇到自己），不放在造型裡 |
| 晶片貓下班了（冷笑話） | P6、P3、P5（手繪抖線） | **台式吐槽感**：死魚眼、面無表情、生活化缺點（厭世、想下班）。主色一個加白；黃色品牌底上用白、粉、藍角色都跳得出來。道具最多一個，例如馬克杯、識別證或便利貼 |
| 賽璐璐研究室（研究員） | P1、P8、P10 | 招牌部件跟動畫製作綁在一起：鉛筆、底片孔、定位孔、攝影表。畫風乾淨、有「動畫感」，但用圓點眼避免少女漫畫臉，以免撞上任何既有角色。主色是紙米白，點綴用紅鉛筆 |
| 晶片貓（主頻道，之後修） | P3、P4、P9 | 拿掉直瞳和琥珀虹膜，改成深色圓點眼；身上的電路紋從 7 條砍到 1–2 條（或只留額頭一個金點）。色數砍到「銀藍＋白＋金點」。保留現有 rig，只換部件繪製 |

## 4. 禁止事項（相似度把關）

- 不寫任何既有 IP 名、角色名、作者名、出版社或品牌名；不寫「in the style of」或「style of」。由 `r2_prompts.py` 的 `BANNED` 清單自動檢查，並附反例測試。
- 避開高辨識組合：
  - 黃色電氣鼠形加紅臉頰；
  - 藍色圓頭貓、沒有耳朵、腹部口袋、紅鼻、鈴鐺；
  - 白色小熊或倉鼠形、點點眼、粉臉頰的三人組；
  - 灰色大肚子、坐姿的森林精靈；
  - 粉紅圓球、短手。
  - 生出來像這幾種的直接淘汰（見第二輪報告的相似度表）。
- 同一頻道內只換物種和主色，不要拼貼多個知名 IP 的招牌部件。
